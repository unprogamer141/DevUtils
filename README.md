## 💡 Why this exists

I kept needing these tools daily – but every one required opening a different website, loading ads, or waiting for JavaScript frameworks. So I built a **single HTML page** that works offline, loads instantly, and has everything in one place.

---

## 📦 How to use

1. Clone the repo or download `index.html`
2. Open it in any browser
3. All tools work 100% offline

```bash
git clone https://github.com/unprogamer141/DevUtils.git
cd DevUtils
open index.html
